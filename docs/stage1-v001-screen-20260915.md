## Interpretation

The instability is **score-side, not verdict-side**. The arm's recall of the
five pits wobbles 1–3 per run while its discipline (always FIX, never a false
positive, never praise) is perfectly stable. The pass gate sits exactly at the
arm's modal score (3 hits), so the binary outcome flips on hit-count noise with
zero change in underlying behavior.

This also bounds the "case-intrinsic" hypothesis: the case is not broken — its
pit set discriminates arms by recall distribution (devin arms score 3.0–4.0,
this arm sits at 1–3). `A-ea80d793` is a **boundary-margin case for mid-recall
arms**: stable for arms far from the gate, binary-unstable for arms on it.

## Protocol amendment driven by this screen

Binary pass/fail is the wrong stability metric for partial-credit cases. Record
the **score distribution and the arm's distance to the pass gate**:

- an arm whose modal score is far from the gate: binary flip = real event
- an arm whose modal score sits on the gate: binary flip = expected noise; the
  stable quantity is the per-pit hit vector and hit-count distribution
