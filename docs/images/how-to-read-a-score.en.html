How to read an AMBER score

① One question set

24 real-work tasks; each one is a "case"
Grouped into 10 "axes" (skills)
Building
CodingDeliveryOpsRequirementsConvergence
Judging
UIVisionDefenseAttributionReview
↓

② Every case ends one of three ways

Passevery check passed
Failone check missing is a fail (8 of 9 = fail)
NAvoided or on hold: counts as neither a pass nor a fail
↓

③ Total

cases passed ÷ 24
If any case is NA, add a prime ' to the number
The denominator is the size of the question set (24 now); NA never shrinks it
↓

Example: claude-sonnet-5-5

19 pass + 4 fail + 1 NA = 24
written 19'/24
